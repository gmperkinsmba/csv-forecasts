Settings and model

Available engines: Baseline comparison and optional local TimesFM 2.5.

TimesFM 2.5: Use a local TimesFM 2.5 checkpoint. The app does not download model files. Reports record the package version, checkpoint ID, and weight hash.

Data handling: CSV contents stay in memory for this session. No key, network service, or upload destination is configured.

Metric rules: MAE works for negative and zero values. MASE shows n/a when the training scale is zero.
